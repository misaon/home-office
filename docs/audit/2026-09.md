## Findings and changes in progress

| Area             | Finding                                                                                     | Remediation                                                                                      |
| ---------------- | ------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| Event sourcing   | Concurrent commands decide against the same pre-append projection                           | Serialize decision, append and projection application; failed commands do not poison the queue   |
| Event replay     | Repeated events could double-count usage and chat                                           | Ignore already-applied sequence numbers                                                          |
| Storage          | Any Zod replay error silently archives the database and starts empty                        | Fail with the database preserved; require an explicit migration or restore                       |
| Subscriptions    | Unbounded queues, stale subscribers, abort-listener leaks                                   | Bounded queues, constant-time dequeue, disposal on cancellation, overflow and consumer return    |
| Runner protocol  | Malformed JSON escapes parsing; hello/spawn/disconnect can hang                             | Validate state and messages; bound connection/spawn time; reject and close on failure            |
| Runner output    | Exit can overtake stdout; unlimited line and socket buffering                               | Drain both streams before exit; bound output lines and queued bytes                              |
| Session shutdown | Database closes while sessions still run                                                    | Track pending starts and running promises; abort and await cleanup                               |
| Credentials      | Secrets temporarily created with default permissions; concurrent writes lose updates        | Atomic owner-only replacement and serialized mutations                                           |
| Keychain         | Shell subprocess exposes credential in argv                                                 | Native asynchronous `Bun.secrets` API, retaining service/account names                           |
| Static serving   | Malformed percent encoding throws; symlinks escape root; dashed sprite names cached forever | Validate paths, resolve symlinks, revalidate mutable files, add response security headers        |
| Network          | Remote plaintext bind allowed despite documentation promising TLS                           | Validate loopback-only binding until a real remote TLS mode exists; reject cross-origin requests |
| Docker           | Requests can hang; logs and swap unbounded                                                  | Request deadlines, bounded local logs, memory-plus-swap limit                                    |
| Publishing       | Force pushes can overwrite later work                                                       | Normal pushes surface conflicts without overwriting branches                                     |
| MCP              | A session can read another floor's task by ID                                               | Enforce project ownership on task status                                                         |
| Domain           | Removing reviewers/floors can orphan live sessions; task parents can cross floors           | Validate session/task ownership and deletion preconditions                                       |
| Project identity | Changing repository reuses task volumes from a different repository                         | Repository identity is immutable; create a new floor                                             |
| Chat             | Schema accepts both destination fields or whitespace-only messages                          | Exactly one destination and nonempty trimmed text                                                |

## Lifecycle, delivery and CLI batch

Daemon startup and shutdown now use `AsyncDisposableStack` with an atomic, refreshed proper-lockfile
lock. Failed startup releases acquired resources; repeated stop calls await the same cleanup. Scheduled
work, intake, garbage collection and delayed boss messages are awaited before closing storage. Restart
reconciles interrupted sessions and their managed containers, leaving affected tasks blocked for explicit
resumption. A manual run using a temporary state directory and an unavailable Docker socket verified
HTTP health, duplicate-instance rejection, simultaneous stop calls and successful restart without touching
existing office state or containers.

Work reports are finalized after publication succeeds. Delivery failures now propagate and block the
task; an existing open PR is reused. Git bridges disable hooks/fsmonitor and clone without hardlinks;
new branches use immutable task IDs, existing recorded branches remain valid. Refreshing a remote
repository no longer prunes or overwrites unpublished task branches. GitHub URL matching is anchored,
remote inputs require HTTPS/SSH without embedded passwords, and GitHub polling paginates all open
issues instead of repeatedly seeing only the newest 50. Cancellation listeners and subprocess deadlines
are bounded. CLI task assignees resolve within their floor, ambiguous session suffixes fail, relative
paths resolve on the client, mutually exclusive options are rejected, and Docker/image failures give
`ho doctor` a nonzero exit code. IPv6 daemon URLs are bracketed.

Oxc upgraded to oxlint 1.82.0 / oxfmt 0.67.0. The esbuild override to 0.28.2 removes the vulnerable
Drizzle Kit transitive version; `bun audit` reports no vulnerabilities across 365 packages. This override
requires continued compatibility checks when Drizzle Kit changes. Full compiler/lint/format/Knip checks
pass. No new tests were written.

## UI, build and CI batch

foreground-only polling. Setup no longer issues duplicate doctor requests; editing a repository source
immediately invalidates the previous inspection. Chat only clears a draft after a successful send,
blocks duplicate sends, respects IME composition and remounts floor-specific state on navigation.
React hook and accessibility rules are enabled. CSS participates in Knip through its owning workspace;
unused configuration exceptions were removed. Bun's text lockfile is visible in diffs.

compiler processes to four and fails if the desktop devkit is missing. `bun run devkit` installs a
revision- and checksum-pinned Hutch archive locally, avoiding execution of a changing remote installer.

CI pins actions to verified commit SHAs, uses read-only checkout credentials, checks compiled CLI/runner
and UI builds, and runs dependency audits. Releases validate version tags and main ancestry, inject the
version through configuration, and isolate publication privileges in a separate job. Dependabot tracks
Bun, Actions and Docker weekly. The release workflow remains unsigned; no release was published by the
audit. The local macOS toolchain setup and all 16 static targets passed.
