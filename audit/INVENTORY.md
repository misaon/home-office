## 8. Data-flow map

### Where state lives

1. **`~/.config/home-office`** (or `$HO_HOME`, created `0700`), guarded by a `proper-lockfile` on
   `daemon.lock`: `config.json`, `ho.db` (SQLite), `daemon.json` (host/port/**bearer token**/pid), `logs/`.
2. **`ho.db`** — the only durable state: one append-only `events` table (Drizzle schema in
   `packages/store/src/schema.ts`, migration `drizzle/0000_boring_clint_barton.sql`).
3. **In-memory `ReadModel`** (`packages/core/src/model/read-model.ts`) — Maps of projects/agents/tasks/
   sessions/mail + a chat array + `lastSeq`, rebuilt by folding the log through `applyEvent`.
4. **Secret store** — macOS Keychain via the `security` CLI, or a `0600` JSON file. Never in the event log.
5. **Docker** — containers, task volumes and images are external state reconciled by
   `recover-sessions.ts`, `housekeeping.ts` and `gc.ts`.
6. **UI client state** — Zustand store + TanStack Query cache in the webview; the office simulation state
   (`@ho/sim` world) is derived per frame and never persisted.

### Who talks to whom, over what

```
                     ┌───────────────────── apps/desktop (Electrobun, Bun main process) ─────────────┐
                     │  src/bun/index.ts: single-instance lock → startDaemon() in-process → window   │
                     └───────────────┬──────────────────────────────────────────────────────────────┘
                                     │ loads http://host:port/  (UI bundle + /assets/, unauthenticated)
                                     ▼
   packages/ui (React 19 + PixiJS 8)  ──oRPC over WebSocket /rpc──►  packages/daemon
     • token via `ho.bearer.<token>` subprotocol (browsers cannot set headers)
     • queries/mutations + 3 event-iterator streams: events.subscribe, sessions.stream, office.presence
     • office.delivered is the animation's back-pressure ack

   apps/cli (`ho`) ──oRPC over WebSocket /rpc, Bearer header──► packages/daemon
     • can also start the daemon in-process (`@ho/daemon` is a direct dependency)

   packages/daemon
     ├─ Bun.serve: /health, /rpc (WS, oRPC), /mcp (MCP gateway), /runner (WS gateway), else static UI
     ├─ same-origin check on every request; bearer token on /rpc and /runner
     ├─ commands: RPC handler → @ho/core command fn → Result<NewEvent[]> → store.append → publish
     ├─ store.append (bun:sqlite, one transaction) assigns seq/id/at → subscribe fan-out
     ├─ scheduler: fold read-model → planSessionStarts (pure) → SessionManager applies
     └─ office gate: while a UI viewer is present, consequential actions wait for `delivered`
            │
            ├─ @ho/sandbox-docker ──HTTP over /var/run/docker.sock──► Docker Engine
            │      creates the agent container per session (image variant per provider)
            │
            ├─ agent container ──WS ho.runner protocol──► daemon /runner   (packages/runner inside)
            │      runner spawns the provider CLI; stdio is bridged as runtime events
            │
            ├─ agent container ──HTTP MCP──► daemon /mcp  (tools that let the agent report progress)
            │
            ├─ @ho/runtime-claude-code : argv + `--output-format stream-json` NDJSON → runtime events
            ├─ @ho/runtime-acp        : stdio JSON-RPC (ACP) → runtime events
            ├─ @ho/intake-github ──`gh` CLI──► GitHub Issues → mail.received + task.created
            ├─ @ho/secrets ──`security` CLI / 0600 file──► credentials injected into containers
            └─ git-bridge image ──`git`──► the user's repository clone/mirror
```

### The three protocol surfaces

| Surface         | Transport                                                                        | Schema authority                                               |
| --------------- | -------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| UI/CLI ⇄ daemon | WebSocket, oRPC RPC protocol, bearer token (header or `ho.bearer.*` subprotocol) | `packages/protocol/src/contract.ts`                            |
| runner ⇄ daemon | WebSocket `/runner`, custom JSON frames                                          | `packages/protocol/src/runner.ts`                              |
| agent ⇄ daemon  | Streamable-HTTP MCP at `/mcp`                                                    | `packages/protocol/src/mcp.ts` + `@modelcontextprotocol/sdk`   |
| daemon ⇄ Docker | HTTP/1.1 over unix socket via `fetch({ unix })`                                  | `packages/sandbox-docker/src/api.ts` (Zod-validated responses) |
